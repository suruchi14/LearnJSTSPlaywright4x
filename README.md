# JavaScript and TypeScript Playwright Learning Repository

This repository is a beginner-friendly practice space for learning JavaScript fundamentals and preparing for TypeScript and Playwright automation work.

## Overview

The project contains hands-on JavaScript exercises focused on:

- JavaScript basics
- Keywords and identifiers
- Variable declaration rules
- Comments and naming conventions
- JavaScript syntax fundamentals

## Getting Started

### Prerequisites

- Node.js installed on your machine
- A code editor such as VS Code

### Run a JavaScript file

```bash
node 01_Chapter_JS_Basics/01_helloworld.js
```

Or run exercises from the keywords and identifiers section:

```bash
node 02_chapter_JS_Keywrods_Identifiers/09_IQ.js
```

## Learning Goals

- Understand JavaScript syntax and structure
- Learn proper identifier naming rules
- Practice writing valid JavaScript code
- Build a foundation for TypeScript and Playwright automation
